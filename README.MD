## 🚀 Featured Projects

### 01 / DataGuard

**Lightweight Data Quality Validation Tool**

A Python-based data quality checker designed to identify common issues in CSV datasets.

The project started as a CS50 Python final project and is being designed with modularity in mind, allowing its validation core to be reused in larger analytical applications.

**Planned capabilities:**

- CSV loading and structural validation
- Missing-value detection
- Duplicate identification
- Data consistency checks
- Structured validation results
- Command-line interface
- Automated tests

**Tech:** `Python` `CSV` `CLI` `pytest`

**Status:** In Development

---

### 02 / DeciNexus

**Intelligent Decision Support Platform**

DeciNexus is an evolving software project exploring how business intelligence, predictive analytics, and artificial intelligence can support operational and strategic decisions.

The concept combines traditional BI capabilities with intelligent analytical components.

**Planned capabilities:**

- Integration with existing data sources
- Analytical dashboards and business metrics
- Data quality and validation modules
- Predictive analytics
- AI-assisted recommendations
- Decision-support workflows

**Focus:** `Python` `SQL` `Business Intelligence` `Machine Learning` `Decision Support`

**Status:** Architecture & Research
